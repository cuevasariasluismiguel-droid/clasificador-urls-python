Clasificador de URLs en Python

Descripción

Este proyecto consiste en un programa desarrollado en Python que clasifica direcciones web según sus características y terminaciones de dominio.

Funcionalidades

- Comprueba si una dirección comienza con "https://".
- Identifica terminaciones como ".edu" y ".com".
- Clasifica las direcciones según las condiciones establecidas en el programa.

Tecnologías utilizadas

- Python 3
